Claricite

A powerful, cross-platform command-line utility engineered to verify bibliographic references in academic PDF files and flag unverifiable or hallucinated citations.

🔍 Native local reference extraction (with optional GROBID support)
🌐 Real-time cross-referencing with major academic databases
📊 Generates clean, actionable HTML logs of unverifiable sources
🚀 Single-file, self-contained binaries with zero dependencies
