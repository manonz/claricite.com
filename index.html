Claricite

Verify references in academic PDFs and detect unverifiable or AI-hallucinated citations. A fast, cross-platform command-line tool for researchers, reviewers, and publishers.

🔍 Native local reference extraction (with optional GROBID support)
🌐 Cross-references citations against major academic databases
📊 Generates a clear HTML verification report
🚀 Portable single-file binaries with no installation required
